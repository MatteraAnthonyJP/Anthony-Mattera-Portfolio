## Publicly Avalible Projects
### AR Puzzle Game: GEARS
A mobile + AR hybrid game inspired by Tetris. The goal is to rotate gears into a "stuck gear" on the board to break it.

**Role in Development**: Designer and Developer-
Gameplay, UI, AR Foundation

**Note:** Solo project

**In Depth Description of role**
Developed from start to finish, this mobile AR hybrid game includes a save/load system, custom shaders, and a experience that can adapt between augmented reality and traditional flat-screen modes during gameplay

**Tools Used**
Unity, C#, Blender (for gear modeling), Shader Graph, AR Foundation


### Educational Project - Drawing The Night Sky
A Educational game made as a capstone project for a musuem in Carter Lake, GA. The Purpose of the game is to help children learn to be able to idenifty constelations by drawing together the stars in the night sky. This was achieved using real star data from the Yale Bright Star Cattelogue.

**Role in Development**: Data Validation, Gameplay logic.

**In Depth Description of role**
I was mainly in charge of finding and loading the actual star data from a Bytes file that was publiclly avalible from Yale, as well as adding the gameplay functionality of actually drawing between the stars. I also had to personally validate each and every connection between stars needed in order to form the constelations. 

**Tools Used**
Unity, C#, json reading
